Direct shortcuts

Shortcuts live only in Settings → Web shortcuts. Give each one a key and an exact URL. Pressing that key anywhere in Zenou, outside a text field, turns this whole tab into that website at once, so the address bar and the page both become the site you saved. Open shortcut does the same, and nothing ever loads inside the stage.

Masking

Mask swaps this tab’s title and favicon for a school-friendly name. about:blank writes the same player into a blank window so the address bar reads about:blank, Chrome allows it, some browsers limit popups.

What is honest

No page can force a server to allow framing. Sites that send frame-ancestors or X-Frame-Options will stay blank here. Magma is linked as a separate proxy app because its own service worker needs a top-level page.
